# 产品库模板填写说明

模板文件：

- `docs/product_catalog_template.xlsx`

## 使用方式

1. 用 Excel、WPS 或表格软件打开 `product_catalog_template.xlsx`。
2. 复制示例行，改成真实产品信息。
3. 真实产品的 `ready_to_import` 填 `yes`。
4. 示例行保持 `no` 或直接删除。
5. 每个产品一行，不要合并单元格。

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `ready_to_import` | 是 | 真实要导入的产品填 `yes`，示例或草稿填 `no`。 |
| `brand` | 是 | 品牌名，例如 `SK-II`、`ANESSA`。 |
| `name` | 是 | 产品名，建议写用户常搜的名字，例如 `神仙水`、`小金瓶防晒`。 |
| `category` | 是 | 使用项目已有分类，见下方分类表。 |
| `volume` | 否 | 规格，例如 `30ml`、`50g`。 |
| `image_url` | 否 | 产品图片链接，建议用品牌官网或官方旗舰店主图链接。 |
| `image_file` | 否 | 本地图片文件名，例如 `sk2-pitera-essence.jpg`。如果同时填写图片链接和本地文件，后续导入脚本优先用本地文件。 |
| `ingredients` | 否 | 核心成分，用 `、` 分隔。 |
| `efficacy` | 否 | 功效描述，用 `、` 分隔。 |
| `suitable_skin` | 否 | 适合肤质，例如 `所有肤质`、`干性、敏感性`。 |
| `usage_instructions` | 否 | 使用方法，写一句用户能看懂的话。 |
| `usage_steps` | 否 | 适合步骤，例如 `护肤`、`底妆`、`唇妆`。 |
| `product_features` | 否 | 产品特点，例如 `保湿、控油、持妆`。 |
| `suitable_regions` | 否 | 适合区域，例如 `全脸`、`T区、脸颊`。 |
| `suitable_scenes` | 否 | 适合场景，例如 `通勤、拍照、干燥天气`。 |
| `source_url` | 建议填 | 信息来源链接，方便之后核对。当前后端不会展示这个字段。 |
| `notes` | 否 | 给自己看的整理备注。 |

## 可用分类

`洁面`、`爽肤水`、`精华`、`乳液`、`面霜`、`眼霜`、`防晒`、`面膜`、`底妆`、`遮瑕`、`定妆`、`眉眼`、`唇妆`、`腮红修容`、`工具`、`香氛`、`小样`、`其他`

## 整理建议

先做 50 个高频产品即可。优先覆盖：

`洁面`、`爽肤水`、`精华`、`面霜`、`防晒`、`底妆`、`遮瑕`、`定妆`、`唇妆`、`腮红修容`

建议从品牌官网、产品包装、官方旗舰店文字整理信息。不要复制大段商品详情，产品库里只需要能支持搜索、加入化妆柜和生成建议的短信息。

## 产品图片

可以在表格里记录图片，但不建议直接把图片嵌入单元格。后续导入数据库时更稳定的方式是：

1. 如果图片来自网页，在 `image_url` 填官方图片链接。
2. 如果图片已经下载到本地，在 `image_file` 填图片文件名。
3. 后面导入脚本会把图片保存到后端上传目录，并把文件名写入产品的 `photo` 字段。

建议图片命名用英文和数字，例如：

`sk2-pitera-essence.jpg`
`anessa-perfect-uv-sunscreen.jpg`
`esteelauder-double-wear-foundation.jpg`
